Cari ROOT CAUSE dari bug editor, formatting, dan submit secara end-to-end.

Bug yang harus diperbaiki:

2. Saat mengubah format tulisan, selection/caret bermasalah.

==================================================
2. BUG KRITIS: DESKRIPSI HILANG SAAT SUBMIT
==================================================

Ini merupakan bug tambahan yang WAJIB diprioritaskan.

Saat user klik:

SIMPAN ARTIKEL

deskripsi/isi artikel tiba-tiba menjadi kosong/hilang sebelum proses submit benar-benar selesai.

Cari root cause spesifik.

Periksa kemungkinan berikut:

A. Form di-reset terlalu cepat:

setContent('');
setDescription('');
editorRef.current.innerHTML = '';
resetForm();
setFormData(initialState);

dipanggil SEBELUM:

await createArticle(...)

selesai.

B. useEffect menulis ulang editor:

useEffect(() => {
  editorRef.current.innerHTML = content;
}, [content]);

kemudian saat submit ada state berubah:

isSubmitting
uploading
thumbnailUrl
attachmentIds
tagIds

yang menyebabkan component re-render dan content menjadi empty/stale.

C. submit handler membaca state lama/stale:

content

padahal:

editorRef.current.innerHTML

masih memiliki isi terbaru.

D. state content di-clear untuk loading state.

E. modal close/reset logic terpanggil sebelum response backend success.

F. parent component mengubah key prop saat submit sehingga editor di-remount.

G. conditional rendering seperti:

isSubmitting
  ? loadingComponent
  : editor

yang menyebabkan editor component unmount.

H. reset state pada finally:

finally {
  resetForm();
}

Padahal reset hanya boleh saat success.

I. selected article / create state tercampur sehingga submit memicu initialize ulang editor kosong.

Agent WAJIB menemukan root cause aktual di source code.

Jangan hanya menambahkan workaround.

==================================================
4. RESET FORM HANYA SAAT SUCCESS
==================================================

Cari semua code:

resetForm()
clearForm()
clearEditor()
setContent('')
setTitle('')
setCategoryId('')
setTagIds([])
setThumbnail(...)
setAttachments([])

Pastikan code tersebut hanya dipanggil setelah:

article benar-benar berhasil disimpan.

Jangan reset di:

try sebelum await
finally
startSubmit
upload start

Contoh:

try {
  setSubmitting(true);

  const result = await saveArticle(payload);

  if (!result.success) {
    throw new Error(...);
  }

  // HANYA DI SINI
  resetForm();
  closeModal();
  refreshArticles();
} catch (error) {
  // JANGAN RESET FORM
  showError();
} finally {
  setSubmitting(false);
}

5. SNAPSHOT FORM SEBELUM ASYNC SUBMIT
==================================================

Sebelum request async dijalankan, ambil snapshot seluruh input.

Contoh konseptual:

const currentHtml =
  editorRef.current?.innerHTML ??

const submitSnapshot = {
  title: title.trim(),
  publicationDate,
  categoryId,
  tagIds: [...tagIds],

Gunakan snapshot ini selama seluruh submit pipeline.

Jangan membaca ulang state yang bisa berubah di tengah proses tanpa alasan.
