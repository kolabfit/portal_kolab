Bertindaklah sebagai senior full-stack developer, backend engineer, dan cloud storage integration engineer.

Pelajari terlebih dahulu seluruh source code Portal Ko+Lab terbaru sebelum melakukan perubahan.

Project menggunakan:

- Frontend: React + TypeScript + Vite
- Backend: Node.js + Express
- Database: MySQL
- Authentication: JWT
- Existing file system/storage:
  - file_blobs
  - /api/files
  - repository upload
  - avatar/photo
  - article image
  - article attachment
  - URL asset di beberapa fitur
- Existing audit log:
  - system_logs

Tujuan utama development ini adalah:

Memigrasikan SELURUH fitur Portal Ko+Lab yang melakukan upload file agar file baru disimpan di Kroombox CDN, bukan lagi menyimpan binary file di MySQL atau menggunakan mekanisme upload lama.

Gunakan Kroombox CDN API sesuai guide yang telah diberikan sebelumnya.

Jangan melakukan rewrite besar terhadap aplikasi.

Lakukan migration secara bertahap, backward-compatible, dan aman.

1. SECURITY CREDENTIAL

Credential Kroombox CDN tidak boleh ditulis di source code.

Gunakan environment variable backend:

KROOMBOX_CDN_BASE_URL=https://api-cdn.kroombox.com
KROOMBOX_CDN_API_KEY=<SET_DI_BACKEND_ENV>
KROOMBOX_CDN_JWT=<SET_DI_BACKEND_ENV>
KROOMBOX_CDN_PROJECT_ID=<SET_DI_BACKEND_ENV>

Jangan pernah expose:

KROOMBOX_CDN_API_KEY
KROOMBOX_CDN_JWT

ke:

Frontend React
VITE_*
localStorage
API response
console.log
