Bertindaklah sebagai senior full-stack developer.

Pelajari terlebih dahulu seluruh source code Portal Ko+Lab versi terbaru, khususnya implementasi role STUDENT, dashboard mahasiswa, sidebar/navigation, profile/account, serta source data yang sudah dikelola oleh role ADMIN.

Fitur Admin berikut sudah tersedia dan menjadi source of truth:
- Kelola Member
- Kelola Startup
- Kelola Magang
- Kelola Workload

Jangan membuat ulang database atau menduplikasi data.

Tugas sekarang adalah mengembangkan role mahasiswa agar mahasiswa dapat melihat status dirinya secara lengkap sebagai Member Ko+Lab.

Berdasarkan tampilan role mahasiswa saat ini, fitur existing seperti Overview, Repository, Informasi, Event, Schedule, dan Broadcast tetap dipertahankan.

Tambahkan informasi berikut:
1. Status Member Ko+Lab
2. Startup yang diikuti
3. Job Desk di startup

5. Startup tempat magang

Jangan merusak fitur role mahasiswa existing.

20. SECURITY

Mahasiswa hanya boleh melihat data dirinya.

Jangan menerima:

nim
studentId
memberId

dari frontend untuk menentukan siapa yang dibaca.

Gunakan:

req.user.id

dari JWT/session.

Test:

Student A

tidak boleh melihat:

Student B

dengan mengubah request.


21. DATA YANG TIDAK BOLEH DIKIRIM

Jangan response:

password
password_hash
JWT
database credential
secret
internal audit data

Quota/storage internal tidak perlu ditampilkan di halaman Status Saya kecuali memang dibutuhkan oleh Repository.


22. HINDARI N+1 QUERY

Jangan:

1 query student
1 query startup
1 query internship
1 query lecturer
1 query untuk setiap workload

Gunakan:

JOIN
LEFT JOIN
GROUP BY
bulk query

atau beberapa query terstruktur yang efisien.

Karena endpoint hanya mengambil satu mahasiswa, beberapa query terpisah masih dapat diterima, tetapi jangan melakukan loop query per workload.


23. EMPTY STATE

Tangani kondisi normal.

Tidak punya startup:

Belum tergabung dalam startup.

Tidak magang:

Belum memiliki data magang.

Tidak punya workload:

Belum memiliki workload aktif.

Jangan menampilkan error.


24. LOADING STATE

Saat API loading:

skeleton
spinner

Gunakan style existing.

Jangan tampilkan:

undefined
null
NaN


25. ERROR STATE

Jika gagal load:

Data status belum dapat dimuat.

Tambahkan:

Coba Lagi

Jangan logout user hanya karena endpoint status gagal.
